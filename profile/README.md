# Agent IX

Agent IX builds agentic engineering tools — specification, verification, and
delivery infrastructure designed to be driven end-to-end by autonomous AI
agents under human direction.

Most of what you'll find across these repos is built that way: agents write
the code, run the gates, and open the pull requests, with a human owner
setting direction and making the calls that matter. We're candid that this is
still early — some repos are unfinished, some gates are red, and quality work
is ongoing alongside feature work.
